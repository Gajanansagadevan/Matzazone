# MatzaZone 📐

Website link - https://gajanansagadevan.github.io/Matzazone/contact-us.html

A mathematics educational website dedicated to theorems, famous mathematicians, and the history of mathematics.

## About

MatzaZone is a static HTML website that explores the world of mathematics — from foundational theorems to the stories of the greatest mathematicians in history. It serves as a learning resource for Grade 10 and Grade 11 students, as well as anyone with a passion for mathematics.

## Pages

| Page | Description |
|------|-------------|
| `index.html` | Home page with introduction and featured quotes |
| `mathematician.html` | Overview of famous mathematicians |
| `GR.10 Theorems.html` | Grade 10 mathematics theorems |
| `GR.11 Theorems.html` | Grade 11 mathematics theorems |
| `about.html` | About the author |
| `contact-us.html` | Contact form |

## Getting Started

Since this is a static website, no installation or build tools are required.

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/matzazone.git
   ```
2. Open `index.html` in any web browser.
